## Amounts re-derived for routing (threshold reasoning)

- **Scenario 2: `2,500,000₮ wire` → `6,500,000₮` via Banksüljee (RTGS).**
  - Reasoning: the RTGS routing threshold is ₮5,000,000. 2,500,000₮ is **below** ₮5m, so labelling it a
    wire/RTGS is internally contradictory — it would actually route via ACH+ and collapse the two-rail
    demonstration. Re-derived **above** ₮5,000,000 to **6,500,000₮** (whole tögrög, no float, brief's
    recommended value) so it genuinely routes via Banksüljee (RTGS).
  - Step-up semantics preserved: the scenario's own step-up threshold (550,000₮ [PROPOSED seed value]) is
    unchanged and distinct from the RTGS routing threshold; 6,500,000₮ exceeds both, so step-up
    authentication (US-1.4) is still required and the `403 Forbidden` "step-up required" behaviour is
    intact.
  - **FLAG: rail-driven re-derivation, PO-confirmable.** The 550,000₮ step-up seed and the 6,500,000₮
    demo amount are both PROPOSED/illustrative and should be confirmed by the PO.

- Scenario 1's 500,000₮ was **not** re-derived — it is correctly below threshold and stays ACH+.
- No other monetary amounts changed (per brief: only the rail-driven re-derivation is permitted).
